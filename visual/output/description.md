# Turn engine

The turn-engine component at version 0.5.3 provides ae/game-adapter version 1.0.0 to an illustrative application consumer, which in turn supplies ae/game-rules version 1.0.0 and ae/seating version 1.0.0 and ae/game-clock version 1.0.0 and ae/private-views version 1.0.0 and ae/presence version 1.0.0 and ae/tournament version 1.0.0 and ae/computer-players version 1.0.0 and ae/round-history version 1.0.0 and ae/rules-settings version 1.0.0. The 10 arrows each run from a named output to a required input of the same type and version. Setting values shown are placeholders and secrets appear only as references.
